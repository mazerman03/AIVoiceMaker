AIVoiceMaker

A voice-cloning text-to-speech pipeline. Type text → hear it spoken in a voice fine-tuned from YouTube recordings.

What this is

An end-to-end pipeline that auto-transcribes single-speaker MP3s with Whisper, fine-tunes Coqui XTTS-v2 on that voice, and exposes a local Gradio app for live type-to-speech. Source on GitHub.

Why this page is static

GitHub Pages only serves static files — it can't run a TTS model. So this page hosts pre-generated audio samples. To try the live type-to-speech demo, run python app/gradio_app.py locally after training.

Run it yourself

git clone <repo> AIVoiceMaker
cd AIVoiceMaker
pip install -r requirements.txt
# Drop MP3s into data/raw/, then:
python -m src.preprocess
python -m src.transcribe
python -m src.split_dataset
python -m src.train
python app/gradio_app.py

See HANDOFF.md for the Mac ↔ GPU-PC workflow.

Built with Coqui XTTS-v2 (CPML, non-commercial), faster-whisper, Silero VAD, Resemblyzer, and Gradio.
